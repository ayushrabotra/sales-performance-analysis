# Sales Performance Analysis

## 📊 Project Overview

This project analyzes sales transaction data to understand overall sales performance, profitability, product performance, and sales quantity.

The analysis was performed using Microsoft Excel, with a focus on data cleaning, KPI calculation, exploratory analysis, and business insights.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify key sales and profitability metrics
- Evaluate product-level performance
- Analyze sales quantities
- Identify patterns and trends in the dataset
- Present findings in a clear and business-focused format

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- PivotTables
- Data Visualization
- KPI Analysis
- Business Insights

## 🔍 Analysis Process

### 1. Data Preparation
The raw sales dataset was reviewed and prepared for analysis. Incomplete or unsuitable records were excluded from the final analysis dataset.

### 2. Data Analysis
Excel was used to calculate key performance indicators and examine sales, profit, quantity, and product-level performance.

### 3. Exploratory Analysis
PivotTables and visualizations were used to identify patterns and compare performance across relevant business dimensions.

### 4. Business Insights
The analysis was used to highlight important findings that can support better understanding of sales performance and business decision-making.

## 📁 Project Files

- `Sales_Performance_Raw.xlsx` — Original/raw dataset
- `Sales_Performance_Analysis.xlsx` — Cleaned and analyzed workbook

## 💡 Key Takeaway

The analysis provides a structured view of sales performance and demonstrates how Excel can be used to transform raw transaction data into meaningful business insights.
